COMMANDS

Simple slash commands.

Everything is designed around Discord's slash command system so your staff can quickly find what they need.

/help View all available RuleMaster commands.
/rules View and manage server rules.
/moderation Moderate members and manage warnings.
/suggest Create and manage community suggestions.
/announce Create formatted server announcements.
/stats View server statistics.
/roblox Look up Roblox users and games.
/staff Access staff management tools.
/settings Configure command role permissions.
